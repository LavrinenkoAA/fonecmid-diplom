# Дипломный проект профессии «1C-программист: с нуля до middle»
 
## Инструкция по начальной настройке

Для начала  пользования новой функциональностью проведите следующие настройки:

### 1. Для оповещения через Телеграм о новых документах «Обслуживание клиентов» и их изменений нужно заполнить константы в подсистеме «Обслуживание клиентов»:
        ◦ Токен telegramm 
        ◦ ID группы

#### Создание бота
1. Напишете в Телеграм https://t.me/BotFather команду "/start"
2. Напишите команду "/newbot"
3. Выберите имя вашего бота, которое будут видеть пользователи
4. Выберите идентификатор вашего бота (он должен заканчиваться на "bot")
5. Скопируйте токен, который пришлет BotFather и сохраните его в константу «Токен telegramm»
#### Создание группы
1. Создайте группу в Телеграм
2. Добавьте в группу только что созданного бота
3. Назначьте боту права администратора
#### Получите идентификатор группы
1. Напишите любое сообщение в группу
2. Напишете в Телеграм https://t.me/Getmyid_bot команду "/start"
3. Выберите команду "Select group chat"
4. Выберите вашу созданную группу
5. Нажмите кнопку Отправить
6. Скопируйте ID группы в строке «Select group chat ID", который пришлет Get my id и сохраните его в константу «ID группы»
       
### 2. Для новой функциональности в документе «Реализации товаров и услуг» нужно заполнить константы в подсистеме «Обслуживание клиентов»:
        ◦ НоменклатураАбонентскаяПлата заполняется из справочника «Номенклатура» с соответствующим наименованием, заранее создайте нужную номенклатуру.
        ◦ НоменклатураРаботыСпециалиста заполняется из справочника «Номенклатура» с соответствующим наименованием, заранее создайте нужную номенклатуру.
          
### 3. Для расчёта зарплаты сотрудникам нужно заполнить регистр сведений «Условия оплаты сотрудников» в подсистеме «Кадровые расчеты» с указанием всех сотрудников с их окладами и процент от работ у специалистов.

### 4. В подсистеме «Кадровые расчеты» в справочнике «Графики работы» заведите необходимые виды графиков работы. В обработке «Заполнение графика» выбрать период для расчета, график работ (созданный ранее в справочнике «Графики работы»)  и выходные дни (например: 6,7 для пятидневки, как суббота и воскресенье).

### 5. В справочнике «Пользователи» создайте для каждого сотрудника учетную запись. На вкладке «Права доступа» назначьте каждому пользователю соответствующий должности профили группы доступа. Для нового функционала созданы следующие группы доступа:
        ◦ Специалист: доступно создание документа «Обслуживание клиентов», создание отчёта по выработке специалистов.
        ◦ Менеджер: доступно создание документа «Обслуживание клиентов».
        ◦ БухгалтерИТФирмы: доступно  массовое создание документов «Реализации товаров и услуг», создание отчёта по анализу выставленных актов.
        ◦ КадровикРасчетчик: доступен ввод информации о заработной плате, плановых отпусках, создание отчёта по выработке специалистов, по зарплате и отпускам.
